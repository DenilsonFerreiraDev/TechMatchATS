-TechMatch ATS
Uma aplicação web desenvolvida para ajudar candidatos a otimizar seus currículos para sistemas ATS (Applicant Tracking System), aumentando as chances de passar pela triagem automática de recrutadores.

 Sobre o Projeto
O TechMatch ATS compara uma descrição de vaga com um currículo e fornece uma análise completa de compatibilidade.

A ferramenta identifica palavras-chave relevantes, calcula um ATS Score, apresenta recomendações de melhoria e gera uma versão ATS Friendly do currículo.

 Importante: o sistema nunca inventa experiências, certificações, habilidades ou conhecimentos. Todas as sugestões são baseadas exclusivamente nas informações fornecidas pelo usuário.

 Problema Resolvido
Muitos candidatos possuem boas qualificações, mas seus currículos acabam sendo filtrados por sistemas ATS antes mesmo que um recrutador os visualize.

O TechMatch ATS ajuda a:

Identificar aderência entre currículo e vaga
Encontrar palavras-chave importantes
Localizar competências ausentes
Melhorar a estrutura do currículo
Gerar uma versão ATS Friendly
Aumentar a compatibilidade com sistemas de recrutamento

 Desenvolvimento
Este projeto foi desenvolvido como desafio final do Bootcamp de Aplicações em Inteligência Artificial da DIO, utilizando engenharia de prompt e desenvolvimento assistido por IA através da plataforma Lovable.

Durante o desenvolvimento foram realizados refinamentos para:

Melhorar a análise ATS
Criar diagnóstico detalhado
Adicionar ATS Score visual
Melhorar a experiência do usuário
Organizar o currículo de forma ATS Friendly
Tornar o sistema mais profissional e responsivo
